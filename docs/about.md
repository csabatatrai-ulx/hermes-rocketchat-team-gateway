# About

Rocket.Chat Team Gateway is a [Hermes Agent](https://hermes-agent.nousresearch.com/) platform plugin that brings Hermes into Rocket.Chat, the open source team chat that organizations run on their own servers. It was built for rooms where many people share one bot, and released as open source under the [Apache License 2.0](https://github.com/csabatatrai-ulx/hermes-rocketchat-team-gateway/blob/main/LICENSE).
